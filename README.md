# BitFoots — Website Recreation (v2)

Static recreation of the current bitfoots.xyz site in pure HTML / CSS / vanilla JS, built from the provided reference screenshots (desktop + mobile).

## Structure
```
index.html
css/style.css
js/script.js
img/               ← drop production assets in here (see list below)
assets/            ← optional: background audio track
```

## Production assets expected in `img/`
Drop these in and everything wires up automatically, no code changes needed:
- `bitlogo.png` — main wordmark, used in both the hero (`.wordmark img`) and the footer (muted via CSS `filter`). Sized responsively with `object-fit: contain`, so any source resolution will scale correctly.
- `bitfoots_birds_flying.mp4` — hero background video (autoplay, muted, looped). Rendered with `object-fit: cover; object-position: center 65%` inside `.hero__terrain` so it fills the hero without looking over-cropped; adjust `object-position` in `style.css` if the framing needs nudging once the real footage is in.
- `img1.png` … `img17.png` — the 17 collection carousel slides, generated by `buildCarousel()` in `script.js`. Each is fit with `object-fit: contain` inside its square frame.
- `bitfoot-head-01.png` … `bitfoot-head-18.png` — the 18 head grid tiles, generated by `buildHeadsGrid()` in `script.js`. Each is fit with `object-fit: cover` inside its tile.

## What's still placeholder
- **Background music**: `<audio>` tag points at `assets/theme.mp3`, which doesn't exist yet — add the real track and the player will pick it up automatically.
- **FAQ answers** are placeholder copy since the live site only shows collapsed questions in the reference screenshots — replace with final copy from the BitFoots team.
- **X / Twitter, Applications, Status, Manifesto and "Download all 18 heads" links** all point to `#` — wire up the real URLs.

## Fonts
- Display / wordmark: **Silkscreen** (Google Fonts) — closest open match to the blocky pixel wordmark.
- Body & headings: **Lora** (Google Fonts) — matches the serif used for headings and body copy in the reference.
- Icons: **Remix Icon** via CDN.

## Notes on fidelity
Colors, type scale, section order, button styles, the amber/gold accent, the dark navy‑to‑forest gradient, and the fixed bottom‑right music player were all matched directly against the supplied screenshots (desktop and mobile). There is intentionally no hamburger/mobile nav, matching the reference — sections simply restack for narrow viewports.
